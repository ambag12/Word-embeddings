# NLP Feature Extraction & Sentiment Analysis

This repository demonstrates several fundamental NLP techniques and a simple text classification workflow:

- **Text Preprocessing** (tokenization, stop‑word removal, stemming)  
- **Word Embedding** with Word2Vec  
- **Sentiment Scoring** via VADER  
- **Binary Classification** using Logistic Regression  
- **Bag‑of‑Words (BoW)** feature extraction  
- **N‑Gram** generation  
- **One‑Hot Encoding** of categorical data
